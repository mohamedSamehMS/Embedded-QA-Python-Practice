# HackerRank Python Practice

The problems are split into two groups:

- **Core**: highest-value problems for the current Embedded QA learning goal.
- **Optional**: useful general Python problems that are not a current priority.

See the root [README](../README.md) for the full reasoning and priorities.

## Core subdomains

Strings, Sets, Itertools, Collections, Date and Time, Errors and Exceptions, Built-Ins, Python Functionals, Regex and Parsing, XML, Closures and Decorators.

## Small areas

Classes and Debugging are kept as small areas for later practical learning.
